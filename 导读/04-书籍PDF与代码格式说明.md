# 📄 三种 PDF 与 `.ipynb` 到底是什么

## 1. `.ipynb` 是什么？

`.ipynb` = **IPython Notebook**，中文一般叫「**Jupyter 笔记本**」，本质是一个 **JSON 格式的文本文件**，只是后缀名不同。

> [!abstract] 一句话理解
> 它是一个**能直接运行的实验记录本**：一页里既有「说明文字」，也有「代码」，还有「代码跑出来的图」。

打开它你会看到一个个「**单元格 cell**」：

| cell 类型 | 里面是什么 | 作用 |
| --- | --- | --- |
| **Markdown cell** | 中文讲解 + LaTeX 公式 | 相当于书里的正文 |
| **Code cell** | Python 代码 | 点 ▶️ 就能跑 |
| **Output** | 代码的输出（数字/表格/图） | 作者已经帮你跑好的结果，存在文件里 |

所以本书的 notebook = **带可执行代码的教科书**。你可以改任何一个参数（比如把 3 改成 5），重新跑，图立刻变——这是纸质书做不到的。

> [!warning] 三个必知常识
> 1. **必须按顺序从上往下跑**。后面的 cell 会用到前面定义过的变量。
> 2. **`.ipynb` 本身不能双击运行**，要靠 Jupyter / VS Code / PyCharm 这类工具打开。
> 3. **作者跑好的输出默认就在文件里**，所以你即使不跑，也能先看图、看结果。

```json
// .ipynb 的内部结构（简化示意，你可以用记事本打开看）
{
  "cells": [
    { "cell_type": "markdown", "source": ["# 一维数组\n", "这里讲 NumPy 数组…"] },
    { "cell_type": "code",     "source": ["import numpy as np\n", "a_ = np.array([1,2,3])"],
      "outputs": [ { "data": { "text/plain": ["array([1, 2, 3])"] } } ] }
  ],
  "metadata": { "kernelspec": { "name": "python3" } }
}
```

## 2. 仓库里的三种 PDF

作者把同一份内容做了三种形态，**用途完全不同**：

| 图标 | 命名特征 | 例 | 用途 | 建议 |
| --- | --- | --- | --- | --- |
| 📖 **正文** | `LA_01_01_什么是向量.pdf`<br>`LA_01_01_What_Is_a_Vector_EN.pdf` | 有中文名，英文版以 `_EN` 结尾 | 完整讲解，公式推导最全 | **精读**（选一种语言） |
| 🖼️ **PPT 讲义** | 名字里带 **`PPT_`** | `LA_01_01_PPT_什么是向量_中文.pdf` | 正文的图形压缩版，一页一个概念 | **复习** / 快速翻 |
| 📄 **正文前** | `LA_00_...` | `LA_00_Front_Matter_Vol1_EN.pdf` | 目录、前言、作者信息 | 进场先扫一眼 |

> [!tip] 分辨小技巧
> 文件名里**有 `PPT_`** → 讲义；**以 `_EN` 结尾** → 英文版；**以 `_中文` 结尾** → 中文讲义。
> 我把中英文、正文和讲义都分到了不同文件夹，见 [[01-内容索引|内容索引]]。

### 中英文对照怎么用

两边**节次完全一致**，所以最优策略是：

1. 中文正文精读一遍（理解快）。
2. 遇到术语不确定时，打开同节的英文版**只看那一段**，把术语记到下面的对照表里。
3. 以后看英文教材 / 论文 / 报错信息时，你已经认识这些词了。

## 3. 文件命名规则（看懂它，你就不会迷路）

所有文件都是这个格式：

```text
LA_<章>_<节>[_<序号或类型>]_<标题>.<后缀>
```

| 片段 | 含义 | 例 |
| --- | --- | --- |
| `LA` | Linear Algebra | — |
| `01` | 章号 | `LA_01_...` = 第 1 章 |
| `03` | 节号 | `LA_01_03` = 1.3 节 |
| `01`/`02` | 该节的第几个 notebook | `LA_01_03_01.ipynb` |
| `PPT` | 讲义（不是正文） | `LA_01_01_PPT_...` |
| `_EN` / `_中文` | 语言 | `..._EN.pdf` |

> [!example] 举个例子
> `LA_03_02_03.ipynb` = 第 **3** 章第 **2** 节的第 **3** 个代码文件；
> 它的主题是「矩阵乘法第二视角」下的「外积视角」。
> 对应正文是 `LA_03_02_矩阵乘法第二视角.pdf`。
