# 🛠️ 环境配置保姆级教程

> [!info] 你需要什么
> 一台能上网的电脑（Windows / macOS / Linux 都行）。**不需要**预装任何 Python。
> 全部装完大约 15–30 分钟，其中大部分时间是等下载。

## 第 0 步：先认识你要装的三样东西

| 东西 | 作用 | 类比 |
| --- | --- | --- |
| **Python 环境（miniconda）** | 提供 Python 和所有数学库 | 厨房 |
| **Jupyter / VS Code** | 打开并运行 `.ipynb` 文件 | 灶台 |
| **Obsidian** | 打开这份导读、看 PDF、记笔记 | 餐桌 |

> [!warning] 一个高频坑：**不要**用系统自带的 Python 直接装包
> 本书需要 numpy / pandas / matplotlib / seaborn / networkx / scikit-learn / statsmodels / sympy。
> 直接 `pip install` 到系统 Python 很容易和系统工具打架。用下面的**独立环境**最稳。

---

## 方案 A（推荐）：Miniconda + conda 环境

**为什么推荐**：一本通吃，出问题最容易搜到答案；`environment.yml` 一键重建。

### A1. 装 Miniconda

1. 打开 https://docs.conda.io/en/latest/miniconda.html ，下载对应系统的安装包。
2. 安装时**勾选**「Add Miniconda3 to my PATH」（Windows）。
3. 装完打开「Anaconda Prompt」（Windows）或终端（macOS/Linux），输入：

```bash
conda --version
```

出现版本号就成功了。

### A2. 创建本书专用环境

先 `cd` 到本仓库根目录（就是有 `README.md`、`代码`、`书籍PDF` 的那一层），然后：

```bash
cd "D:\git\《线性代数不难》\Linear-Algebra-Made-Easy---Learn-with-Python-and-Visualization"

# 用仓库里现成的 environment.yml 一键创建（推荐）
conda env create -f environment.yml

# 如果不想用 yml，也可以手动创建：
# conda create -n ladm python=3.12 numpy pandas matplotlib seaborn networkx scikit-learn statsmodels sympy jupyter -y
```

> [!tip] 国内下载慢？换清华镜像（快很多）
> ```bash
> conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/main/
> conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/free/
> conda config --set show_channel_urls yes
> ```
> 已有的环境想加速装包：`pip install 包名 -i https://pypi.tuna.tsinghua.edu.cn/simple`

### A3. 激活环境并验证

```bash
conda activate ladm
python 导读/工具/test_env.py
```

看到 `环境 OK` 和一圈 ✅ 就说明装好了。

## 方案 B（更轻）：uv 或 venv + pip

> [!note] 适合已经装了 Python 3.10+ 的同学。若你的 Python 是**最新版**（比如 3.14），
> 有些科学计算库可能还没有对应的安装包，这时请改用 Python 3.12（方案 A 或下面的 uv 指定版本）。

```bash
cd <本仓库根目录>

# 方式 1：uv（最快，推荐）
uv venv .venv --python 3.12
uv pip install --python .venv numpy pandas matplotlib seaborn networkx scikit-learn statsmodels sympy jupyter

# 方式 2：原生 venv
python -m venv .venv
.venv\Scripts\activate        # Windows；macOS/Linux 用 source .venv/bin/activate
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 验证
python 导读/工具/test_env.py
```

## 第 2 步：学会打开 notebook

### 方式 1：VS Code（体验最好，推荐）

1. 装 VS Code：https://code.visualstudio.com/
2. 在扩展市场搜并安装：**Python**、**Jupyter**（两个都装）。
3. `文件 → 打开文件夹`，选本仓库根目录。
4. 打开任意 `代码/01-向量/LA_01_01_01.ipynb`，右上角点 **Select Kernel**，
   选 `ladm (Python 3.12)` 或你的 `.venv`。
5. 点每个代码块左边的 ▶️ 运行；或顶部 **Run All**。

### 方式 2：Jupyter Lab（经典）

```bash
conda activate ladm
cd <本仓库根目录>
jupyter lab
```

浏览器会自动打开，左侧就能看到 `代码/` 和 `书籍PDF/`。

> [!warning] 第 12 章必须从正确目录启动
> `LA_12_01_01.ipynb` 和 `LA_12_03_01.ipynb` 用相对路径读取 `X_df_iris.pkl` / `X_df.pkl`。
> 这两个数据文件已经和 notebook 放在**同一个文件夹**（`代码/12-数据矩阵-PCA-协方差/`），
> 所以只要**直接打开这个文件夹里的 notebook** 就没问题。
> 如果你把 notebook 复制到别处，记得把 `.pkl` 一起复制过去。

## 第 3 步：装 Obsidian（看这份导读）

1. 下载：https://obsidian.md/ （免费）。
2. 打开后选 **「打开文件夹作为仓库」（Open folder as vault）**，选本仓库根目录。
3. 打开 `线性代数不难·导读.md`，就是首页。
4. 建议在 `设置 → 文件与链接` 里把「**新链接格式**」设为 **Wikilink**（本导读用的就是这种）。

> [!tip] Obsidian 里怎么跑代码？
> Obsidian **不能**执行 `.ipynb`，点击 notebook 会用系统默认程序打开（或提示你选程序）。
> 分工：**Obsidian 负责「读 + 记 + 导航」**，**VS Code / Jupyter 负责「跑」**。

## 常见报错速查

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| `ModuleNotFoundError: No module named 'numpy'` | 装到别的环境了 | `conda activate ladm` 后重开 Jupyter / 在 VS Code 重选 Kernel |
| VS Code 里点运行没反应、一直转圈 | 没选 Kernel | 右上角 `Select Kernel` → 选 `ladm` |
| 中文/负号显示成方块 | matplotlib 字体 | notebook 里通常已设置；若无，加两行：`plt.rcParams["font.sans-serif"]=["SimHei"]`、`plt.rcParams["axes.unicode_minus"]=False` |
| 3D 图/动画不显示 | 后端问题 | 在环境里 `pip install ipympl`；或直接用 VS Code / JupyterLab 打开 |
| `FileNotFoundError: X_df.pkl` | 工作目录不对 | 在 `代码/12-数据矩阵-PCA-协方差/` 目录下打开该 notebook |
| conda 装包卡住 | 网络 | 换清华源（见上）或改用 `uv pip install` |
| `SyntaxError` / 包版本冲突 | 环境里包太旧 | `conda env update -f environment.yml --prune` |
