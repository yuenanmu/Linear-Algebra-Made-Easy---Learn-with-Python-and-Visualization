## 三、需要修一下的 4 个 notebook

### ⚠️ 1. `LA_01_08_05.ipynb`（L∞ 范数）— 作者笔误

- **位置**：`代码/01-向量/`，第 3 个代码 cell
- **现象**：`NameError: name 'L2_a' is not defined`
- **原因**：这一格是复制上一节改的，变量名 `L2_a` 忘了改；而且原 cell 本身没让 `L2_a` 生效。
- **改法**：把那一格改成

```python
L_inf_a = np.linalg.norm(a, ord=np.inf)   # 默认
L_inf_a                                   # 把变量显示出来
```

- **学习收获**：顺手对比 `np.abs(a).max()`，两者应该相等。

### ⚠️ 2. `LA_04_04_01.ipynb`（手算行列式/伴随矩阵法）— 作者笔误

- **位置**：`代码/04-行列式/`，`determinant()` 函数内部
- **现象**：`NameError: name 'col' is not defined`
- **原因**：循环变量叫 `col_idx`，函数体里却写成了 `col`。
- **改法**：把

```python
det += matrix[0, col] * cofactor    # ❌ 笔误
```

改成

```python
det += matrix[0, col_idx] * cofactor  # ✅
```

- **学习收获**：这正好是「按第一行展开」的拉普拉斯展开，改对之后可以自己打印每一步的余子式。

### ⚠️ 3. `LA_12_03_01.ipynb`（PCA）— 数值精度问题

- **位置**：`代码/12-数据矩阵-PCA-协方差/`，特征值分解那一格（代码 cell 31）
- **现象**：`TypeError: Image data of dtype complex128 cannot be converted to float`
  （`sns.heatmap(Lambda, ...)` 报错）
- **原因**：协方差矩阵理论上对称，但因为浮点误差，上三角和下三角会有 1e-17 级别的差异。
  `np.linalg.eig` 处理非严格对称矩阵时可能返回**复数**特征值（虚部极小），
  于是 `Lambda` 成了复数矩阵，热图画不了。
- **改法**（推荐用**对称矩阵专用**的函数，数值上更稳更快）：

```python
# 原代码：lambdas, V = np.linalg.eig(P)
lambdas, V = np.linalg.eigh(P)     # ✅ 对称/Hermitian 矩阵专用，返回实数
idx = np.argsort(-lambdas)
lambdas_sorted = lambdas[idx]
V = V[:, idx]
Lambda = np.diag(lambdas_sorted)
```

> 如果只想最小改动，也可以在 `np.linalg.eig` 后面加一行：
> `lambdas = np.real(lambdas)`、`V = np.real(V)`

- **学习收获**：这是很典型的「教科书数学 vs 计算机浮点」的差异，以后在任何库（sklearn、statsmodels）里都会遇到，记住 **协方差矩阵永远用 `eigh`**。

### ⚠️ 4. `LA_15_04_01.ipynb`（空手道俱乐部谱聚类）— 数值精度问题

- **位置**：`代码/15-图论-拉普拉斯矩阵/`，特征值排序那一格（代码 cell 29）+ 热图那一格（cell 31）
- **现象**：`TypeError: Image data of dtype complex128 cannot be converted to float`
- **原因**：同第 3 条——拉普拉斯矩阵是对称的，但浮点误差让 `np.linalg.eig` 吐出了复数。
- **改法**：把

```python
lambdas, V = np.linalg.eig(L)      # 或类似写法
```

改成

```python
lambdas, V = np.linalg.eigh(L)     # ✅ 对称矩阵
lambdas_sorted = np.sort(lambdas)
V_sorted = V[:, lambdas.argsort()]
```

- **学习收获**：这一节是谱聚类（spectral clustering）的入门，第二个最小特征值对应的特征向量就是「Fiedler 向量」，决定图怎么切两半。改完之后把 `V_sorted[:, 1]` 画出来看看正负号分界，非常直观。
